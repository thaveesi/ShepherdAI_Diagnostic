# Security

## What the scanner does on your computer

- It reads the settings of AI agents and apps; it never changes them.
- It writes its report, and the deep check's kept copy, into its own folder.
- It keeps its own tools (uv, Python and its libraries) inside its folder.
- It sends nothing unless you answer yes to the deep check. The upload uses an anonymous sign-in
  that can add one package and cannot read anything.

## Supported versions

Fixes go into the latest release.
